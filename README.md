# goit-cs-hw-04

Homework GoIT University Computer Science.

Програма паралельно шукає ключові слова в текстових файлах. Є дві версії:

- **`search_thread.py`** — багатопотокова (`threading`);
- **`search_mproc.py`** — багатопроцесорна (`multiprocessing`, результати збираються через `Queue`).

Обидві версії ділять список файлів між потоками/процесами, вимірюють час виконання
і повертають словник `{ключове_слово: [шляхи до файлів, де його знайдено]}`.

## Вимоги

- Python 3.14+
- [uv](https://docs.astral.sh/uv/) (для встановлення залежностей і запуску тестів)

Сама програма використовує лише стандартну бібліотеку. Залежності потрібні тільки для тестів.

```
uv sync
```

## Використання

```
python search_thread.py <keyword> [<keyword> ...] [-d DIR] [-n WORKERS] [-p PATTERN]
python search_mproc.py  <keyword> [<keyword> ...] [-d DIR] [-n WORKERS] [-p PATTERN]
```

Найпростіший варіант — пошук слова в усіх `.txt` у поточній директорії:

```
python search_thread.py python
```

- Усі параметри, крім фрази для пошуку, задаються **лише через ключі** і мають значення за замовчуванням.
- Ключі можна ставити будь-де: перед фразою, після неї або навіть між її словами.
- Запуск **без аргументів** виводить довідку (те саме, що `-h`).

### Параметри

| Параметр | Обов'язковий | За замовчуванням | Опис |
|---|---|---|---|
| `keyword` | так | — | Фраза або кілька фраз для пошуку (див. [Як задавати запити](#як-задавати-запити)). |
| `-d`, `--dir` | ні | `.` (поточна директорія) | Директорія з текстовими файлами. Приймає абсолютний або відносний шлях: `.` — поточна, `..` — батьківська, `data/sub`, `../other` тощо. Відносні шляхи рахуються від директорії, з якої запущено команду. Пошук рекурсивний (включно з підпапками). |
| `-n`, `--workers` | ні | `search_thread.py`: **4** потоки<br>`search_mproc.py`: **кількість ядер CPU** | Кількість потоків / процесів. Якщо файлів менше, ніж воркерів, зайві не створюються. |
| `-p`, `--pattern` | ні | `*.txt` | Маска імен файлів (glob), наприклад `*.md` або `log_*.txt`. Беріть у лапки, щоб її не розгорнула оболонка. |
| `-h`, `--help` | ні | — | Показати довідку і вийти. |

### Як задавати запити

**Слова без лапок склеюються в одну фразу:**

```
python search_thread.py hello world          # шукає "hello world"
```

**Щоб шукати кілька фраз, беріть кожну в лапки** — кожна стане окремим запитом
(окремим ключем у словнику результатів):

```
python search_thread.py "hello world" "foo bar"    # шукає "hello world" і "foo bar"
python search_thread.py "hello world" python       # шукає "hello world" і "python"
```

> **Обмеження.** Лапки прибирає оболонка ще до запуску програми, тому програма бачить їх лише
> за пробілом усередині аргументу. Лапки навколо окремого слова не помітні:
>
> ```
> python search_thread.py "python" "queue"         # шукає ОДНУ фразу "python queue"
> ```
>
> Тобто кілька запитів розділяються, лише якщо хоча б один із них містить пробіл.

Порожні запити та дублікати відкидаються.

### Як працює пошук

- Регістр **не враховується**: `python` знайде і `Python`, і `PYTHON`.
- Шукається **входження підрядка**: `python` знайде також `pythonic`.
- Файли читаються в кодуванні **UTF-8**.

### Приклади

Шукати слово в поточній директорії (4 потоки, файли `*.txt`):

```
python search_thread.py python
```

Шукати в батьківській директорії:

```
python search_thread.py python -d ..
```

Шукати дві фрази в папці `data` з 8 процесами:

```
python search_mproc.py "thread pool" "process pool" -d data -n 8
```

Шукати фразу в Markdown-файлах (лапки не потрібні):

```
python search_thread.py error handling -d docs -p "*.md"
```

### Приклад виведення

```
Знайдено файлів: 4, потоків: 2

'python': 2 файл(ів)
  - data\a.txt
  - data\d.txt

'queue': 1 файл(ів)
  - data\b.txt

'missing': 0 файл(ів)

Час виконання (threading): 0.0079 с
```

### Обробка помилок

- Якщо директорії не існує, шлях не є директорією або до неї немає доступу, програма виводить помилку
  і завершується з кодом **1**.
- Якщо окремий файл не вдалося прочитати (немає доступу, не UTF-8, зник під час роботи тощо),
  програма виводить повідомлення в `stderr` із назвою потоку/процесу і **продовжує** обробку інших файлів.

## Використання як модуля

```python
from pathlib import Path

from search_mproc import search_multiprocessing
from search_thread import search_threading
from utils import collect_files

files = collect_files(Path("data"), "*.txt")

result = search_threading(files, ["python", "queue"], num_threads=4)
# {'python': ['data\\a.txt', 'data\\d.txt'], 'queue': ['data\\b.txt']}

if __name__ == "__main__":  # обов'язково для multiprocessing на Windows
    result = search_multiprocessing(files, ["python", "queue"], num_processes=4)
```

## Структура проєкту

```
